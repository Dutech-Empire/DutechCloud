
# 🌤️ DUTECHCLOUD — Weather App

DUTECHCLOUD is a modern, responsive weather application built with **React + Vite**.  
It provides real-time weather information with dynamic visuals and a clean user experience.

## 🚀 Live Demo
👉 https://dutech-cloud.vercel.app

## ✨ Features
- 🔍 Search weather by city
- 🌡️ Real-time temperature (°C)
- 🌦️ Dynamic background images based on weather
- 🌙 Automatic night detection
- ⏳ Loading & error states
- 🎨 Adaptive UI (text contrast changes with background)
- 📱 Fully responsive design

## 🛠️ Tech Stack
- React
- Vite
- CSS
- OpenWeather API
- Vercel (Deployment)
